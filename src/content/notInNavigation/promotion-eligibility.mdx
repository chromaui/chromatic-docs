# Promotion code eligibility

We're thrilled to welcome new customers to Chromatic with a signup credit. Check if you're eligible using the criteria below.

#### Criteria

- You have a promotion code.
- You're a new customer. That means you've signed up within the last 7 days.
- Your account is a Git-linked organization account you share with teammates, not your personal account. For example, one linked to a GitHub Organization, Bitbucket Group, or GitLab Team.

<div class="aside">

If you have an email/password account, it must have multiple project [collaborators](/docs/access/collaborators). Promotion codes for email/password accounts will be honored at our discretion.

</div>

#### Not applicable

- Git-linked personal accounts (for example, one linked to your personal GitHub account).
- Accounts that already have existing discounts or promotions applied.
- Existing customers that already use Chromatic in other parts of their organization.

#### Expiration date

The promotion code for new customers will expire 1 year after being applied or when the signup credit is fully used, whichever comes first.

## How to redeem your promo code

In order to redeem your promo code, follow these steps:

1. [Sign up to Chromatic](/start?startWithSignup=true).
2. Add a Git-linked organization account for your GitHub Organization, Bitbucket Group, or GitLab Team.
3. Set up your first project.
4. Run at least one build.
5. Contact us to check eligibility & promo code via in-app chat.
