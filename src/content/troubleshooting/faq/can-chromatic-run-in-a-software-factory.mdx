# Can Chromatic run in a software factory?

Yes. Chromatic runs in your CI on every push, whether a person or an agent wrote the code. To let agents that run in the cloud read build results with no one signed in, create a [service client](/docs/oauth-clients#create-a-service-client) and call the [Chromatic API](/docs/api) with the [client credentials flow](/docs/api#client-credentials-m2m). Requests count toward the API's [rate limits](/docs/api#rate-limits).
