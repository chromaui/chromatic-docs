# Can Chromatic run in a software factory?

Yes. Chromatic runs in your CI on every push, whether a person or an agent wrote the code. Cloud agents can read build results through the [Chromatic MCP server](/docs/mcp); see [Run Chromatic with cloud agents](/docs/cloud-agents) to set it up. When no one is signed in, they can call the [Chromatic API](/docs/api) with a [service client](/docs/oauth-clients#create-a-service-client) instead, using the [client credentials flow](/docs/api#client-credentials-m2m). API requests count toward the [rate limits](/docs/api#limits-and-rate-limits).
