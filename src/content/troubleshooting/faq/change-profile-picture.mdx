# How can I change my profile picture?

It is possible to change the profile picture for email/password and single sign-on (SSO) profiles by using Gravatar. For profiles connected to a Git provider, profile pictures are synced automatically.

To change your profile picture in [Gravatar](https://gravatar.com/), you will need to do the following:

1. Create a Gravatar profile with the email address on your Chromatic profile
2. Assign a profile picture, which will reflect on your Chromatic profile

**Please note**: Gravatar is a third-party service with which we have no affiliation. Currently, there is no other way to change your profile picture in Chromatic.
