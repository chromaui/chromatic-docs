# Are there any restrictions for external collaborators?

External collaborators receive access only to the projects they join. They do not receive access to the containing account.

An external collaborator cannot:

- Link the project to a Git provider.
- Manage account settings or billing.
- Add projects to the account.

Their [project role](/docs/access/collaborators#project-roles) determines what they can do within the project.
