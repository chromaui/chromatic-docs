# Why does my Git access token show as invalid?

An invalid token means Chromatic can't use the Git provider connection for your project. The project's **Manage > Configure** tab shows whose token it uses.

Ask that person to sign out of Chromatic and sign back in through the Git provider. A project collaborator with Developer or Owner access can also select **Replace with your token**. If that option is unavailable, the token holder can reconnect the provider from their [profile settings](https://www.chromatic.com/profile).

[Repository connection troubleshooting](/docs/faq/link-a-repository#repair-a-repository-connection) covers other causes, including provider IP restrictions. If you have additional questions, use our **in-app chat** to contact us or email us at [support@chromatic.com](mailto:support@chromatic.com).
