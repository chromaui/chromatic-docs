# Can my coding agent check Chromatic builds?

Yes. Connect Claude Code, Codex, or another coding agent to the [Chromatic MCP server](/docs/mcp). Your agent can report the latest build on your branch, point out visual changes that look unintended, fix broken stories and accessibility violations, and tell you when a branch is ready to merge. With the Chromatic plugin, your agent also checks the build after each push. Get started with [Chromatic for agents](/docs/agents).
